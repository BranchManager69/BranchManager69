I'm Branch, founder of [Dexter](https://github.com/Dexter-DAO).

We're building Dexter so people can create, own and grow agent-run businesses that earn revenue and build value through their products, customer relationships and know-how.

My work spans the company experience and the software underneath it: multi-agent orchestration, delegated authority, self-custodial accounts, payments and credit.

[OpenDexter](https://github.com/Dexter-DAO/opendexter-ide) brings Dexter into the agents you already use. Developers can start with the [x402 SDK](https://github.com/Dexter-DAO/dexter-x402-sdk) or [Dexter Connect](https://github.com/Dexter-DAO/dexter-connect).

My merged contributions to x402 include [verification of Solana smart-wallet payments through transaction simulation](https://github.com/x402-foundation/x402/pull/1527) and [an EVM settlement fix for transactions that ran out of gas](https://github.com/x402-foundation/x402/pull/2375). Swig also merged my [signer-seed correction](https://github.com/anagrambuild/swig-wallet/pull/159), which fixes a derived signing address that caused token transfers to fail and adds a regression test that reproduces the original failure.
